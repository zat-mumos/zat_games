## Installation & Dependencies

### Dependencies
- ROS2 Humble
- zat_ros2_msgs

### Installation
The installation steps are mentioned below. Use **BASH** shell to execute this commands

```
# to create a workspace

mkdir -p zat_ws/src
cd zat_ws/src
```
```
# git clone the repository in src folder
git clone https://git.inf.h-brs.de/zat-rhein-ruhr/zat-prototype-demo/zat_games.git
```

```
# build and source the workspace

cd ..
colcon build
source install/setup.bash
```
## Usage
As a ROS node:
```console
ros2 run zat_games language_learning
```

With ROS launch:
```console
ros2 launch zat_games language_learning.py
```

## Supported Messages and Topics

| Message Type | Default Topic  |Publisher/Subscriber| Description |
|---------------|------------------|------------------|----------------------------------|
| `GameEntry`        | `/language_learning/game/controller/state` |Publisher| Publishes the state of the game|
| `GameEntryResult` | `/language_learning/game/gui/state` |Subscriber| Subscribes to game entries made in the GUI|
|`String`|`/qt_robot/speech/say`|Publisher|Publishes responses generated by the RAG server|

## Parameters

**Available Parameters:**

| Parameter                | Type    | Default                   | Description                                             |
|--------------------------|---------|---------------------------|---------------------------------------------------------|
| `in_game_topic`              | string  | `/language_learning/game/gui/state`       | Topic for publishing the state of the game                    |
| `rag_service`             | string  | `/language_learning/rag/feedback`                     |           Service in which the response of the rag server is published                   |
| `out_topic`             | string  | `/qt_robot/speech/say`                     | Topic for publishing the feedack                            |
| `pub_period`             | string  | `1.0`                     | Period of published messages                           |
