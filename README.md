# zat_games

Implementation of the games logic for ZAT project.
Implemented games:
* language learning

## Table of Contents

- [Running](#running)
- [License](#license)

## Running

### Language learning game
As a ROS node:
```console
ros2 run zat_games language_learning.py
```

With ROS launch:
```console
ros2 launch zat_games language_learning.py
```
